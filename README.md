# The Backrooms — Forge 1.20.1

A small liminal-space themed Minecraft mod targeting **Minecraft 1.20.1** and **Forge 47.2.0**.

## Included content

- **Almond Water** — a restorative food item, craftable from a glass bottle, sugar, and a glow ink sac.
- **Yellow Wallpaper** — a decorative block crafted from yellow concrete.
- **Humming Light** — a light-emitting block crafted from glowstone dust and iron bars.
- **Old Carpet** — a decorative floor block crafted from yellow wool.
- A dedicated **The Backrooms** creative tab.

The assets intentionally reuse vanilla textures, so no external resource pack is required.

## Build and run

Requires Java 17 and Gradle. From the project directory:

```sh
gradle build
gradle runClient
```

This project uses the ForgeGradle 6 plugin and official Minecraft 1.20.1 mappings.
